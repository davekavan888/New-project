# ORIONIS — Deploy Guide (Easy)

## On laptop (optional test)
npm install
npm run dev
Open http://localhost:5173
Login: any email + password

## Deploy live (phone) — GitHub + Vercel

1. Create new GitHub repo (empty, no README)
2. Upload ALL files from this folder (package.json, src, public, vercel.json, etc.)
3. Do NOT upload a zip — upload the files inside
4. Vercel → New Project → Import that repo
5. Framework: Vite | Build: npm run build | Output: dist
6. Deploy → open the link on your phone

Demo login works without any keys.
