WINDOWS (easiest)
1. Unzip this folder
2. Double-click UPDATE-NOVAFORGE.bat
3. If it asks to login to GitHub, complete login, run again
4. Wait for Vercel (1-2 min)
5. Open https://novaforges.in and press Ctrl+Shift+R

You need:
- Git for Windows https://git-scm.com/download/win
- Access to github.com/davekavan888/New-project

If push fails: install GitHub CLI and run: gh auth login
